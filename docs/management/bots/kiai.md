# Kiai

Kiai is an XP bot that handles our leveling system. 

| Prefix | Website              |
| ------ | -------------------- |
| `/`    | https://kiai.app |

## Public Commands
The general public only has access to two commands: `/rank` and `/leaderboard`. Like all Kiai commands, these run ephemerally, so only the user who ran the command can see the output.

## Staff Commands
Kiai has a number of commands that are better referenced in the [Kiai docs page](https://docs.kiai.app/)——however, there are a couple relevant ones worth mentioning. They are `/settings`, and `/rewards [etc]`. `/settings` needs no explanation——it brings up a button dialog that lets staff make small changes to the settings (XP algorithm, logging, etc.). For `/rewards` there are a number of additional rewards we can link to XP/levels, and this is how role rewards are implemented. If the level role system needs to be changed, this is where to do it.

## Miscelaneous 
Kiai does not have perfect uptime. On occasion, it will go down and crash. Fortunately, the developers of Kiai are friendly and responsive, and have an active support server. If there are any issues, feel free to reach out to them directly and they should be able to look in to any system failures.
